# Екатеринбург — исследовать город

[Открыть интерактивную модель](https://pirrroman.github.io/ekaterinburg-city-explorer/)

Трёхмерный Екатеринбург на Three.js: свободная камера, история застройки с 1720 по 2026 год, основные достопримечательности, улицы и площади. При открытии показан современный город.

## Управление

- Перетаскивание мышью — вращение камеры.
- Правая кнопка или Shift + перетаскивание — перемещение; колесо — приближение.
- WASD или стрелки — перемещение по городу.
- На сенсорном экране: один палец — вращение; два — перемещение и масштаб.
- Выбор года меняет застройку. Кнопки «Центр» и «Кольцово» возвращают к этим местам.
- Кнопка PNG сохраняет выбранный вид.

## Локальный запуск

Нужен Node.js. В папке проекта выполните `npm start` и откройте адрес, который появится в терминале. Установка пакетов не требуется. Можно использовать любой HTTP-сервер статических файлов; открытие index.html через file:// не поддерживается.

## Данные

Современная география основана на OpenStreetMap; рельеф — на Terrain Tiles. Историческая застройка и границы роста города являются реконструкцией, а не точным кадастром для каждого года. Модель предназначена для визуального исследования.

Источники и лицензии сторонних материалов: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), [геоданные](assets/geography/SOURCES.md).

В этой версии нет фильма, музыки, видеопроигрывателя и средств рендеринга видео. Приложение работает в браузере с WebGL2, без аккаунта и серверной базы данных.
